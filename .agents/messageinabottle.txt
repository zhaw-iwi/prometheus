Before doing project work:

1. Read `.agents/CODEX.md` for reusable engineering and milestone practices.
2. Read `.agents/CONTEXT.MD` for PROMETHEUS's purpose, architecture, current
   capabilities, known gaps, and project-specific boundaries.
3. Read `PROJECT.md` from the beginning through `Current milestone state`, then
   stop before `Historical milestones checklist`. Do not read the historical
   audit end to end unless the task depends on an earlier decision; search it
   selectively instead.
4. Check the active branch and worktree, then inspect the README sections,
   implementation, configuration, and neighboring tests relevant to the task.

Before proposing or making changes, give a concise mental model and identify
the specific existing patterns, files, and tests that should guide the work. Do
not restate the documentation at length.

If I provide a milestone goal, define a focused scope and implement it end to
end with the smallest high-value test set and required documentation updates.
Preserve existing architecture and user changes, and do not revert unrelated
work.

When the milestone is complete, report what changed, what was actually
verified, and any remaining risks or unverified areas. Then stop so I can review
and commit.
